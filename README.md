# Sarandi Newsroom Dashboard

Dashboard desktop (Windows) para a equipe de jornalismo da **Rádio Sarandi 103.3**.

Reúne numa tela só: ouvintes online ao vivo, notícias da própria rádio e dos
principais portais (G1, GZH, UOL, CBN), previsão do tempo, alertas de clima
severo, cotações (dólar/euro), próximos jogos de Grêmio e Internacional,
próximos feriados, santo do dia e resultados das loterias.

## Downloads

Baixe o instalador mais recente na aba **[Releases](../../releases)**.

Após instalado, o app se **atualiza sozinho** sempre que uma nova versão é
publicada aqui, reabrindo em tela cheia.

---

Feito para uso interno da Rádio Sarandi. O código-fonte não é distribuído
neste repositório.
